MedPredict AI is an intelligent disease prediction platform that helps users identify likely diseases based on their symptoms using a machine learning model trained on symptom-to-disease data.

Live Demo: https://disease-prediction-xts8bsqf7tullcbh5hd7jg.streamlit.app/

## Why This Project Matters

Healthcare decisions often need to be quick, informed, and accessible. MedPredict AI bridges that gap by turning symptom descriptions into a data-driven prediction using a simple, user-friendly interface. It is designed to help users understand possible disease patterns while promoting early awareness and faster consultation.

## Product Highlights

- Symptom-based disease prediction using machine learning
- Fast and easy-to-use web interface built with Streamlit
- TF-IDF text feature extraction for symptom interpretation
- Logistic Regression classifier for prediction
- Model persistence with joblib for efficient reuse
- Built for real-world prototype and startup-style deployment

## How It Works

1. The system loads symptom data from the dataset.
2. Symptoms are converted into numeric feature vectors using TF-IDF.
3. A Logistic Regression model is trained on the labeled disease dataset.
4. The trained model is saved in the `models/` directory.
5. Users enter symptoms in the app, and the system predicts the likely disease.

## Installation

Clone the repository and install the required packages:

```bash
git clone https://github.com/SARAVANA-R28/Disease-prediction.git
cd Disease-prediction
pip install -r requirements.txt
```

## Run the App

### Train the model

```bash
python main.py
```

### Launch the web application

```bash
streamlit run app.py
```

## Usage

Open the local URL generated by Streamlit and enter symptoms such as:

```text
fever, cough, body pain, fatigue
```

The app will predict the most likely disease based on the trained model.

## Dataset

The project uses `dataset/Symptom2Disease.csv`, which contains symptom text and disease labels. The data is processed and transformed before training the model.
